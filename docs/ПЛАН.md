# План: клиент «Барахолки» (Модуль В, React SPA)

Как пользоваться:
- Шаги строго по порядку, в каждом делаешь **только** то, что в нём написано.
- В каждом шаге: **что знать** (с примером), **что сделать**, **проверка**, **частые ошибки**.
- Примеры написаны на **другом приложении — «Книжной полке»** (книги вместо объявлений).
  Логика та же, имена другие — переносишь на свои файлы.
- Код, который одинаков в любом проекте (слой API, контекст авторизации, защита роутов,
  поле формы), дан как есть: его на чемпионате пишут по памяти, выучи.
- Застрял больше 10 минут — смотри «Шпаргалку» в конце, потом спрашивай.

## Шаг 1. Страницы, роуты, ссылки

### 1а. Страницы → JSX ✅
Из каждой страницы шаблона — только `<main>` в свой файл в `pages/`, хедер — в
`components/Header.jsx`.

| HTML | JSX |
|---|---|
| `class=` | `className=` |
| `for=` | `htmlFor=` |
| `novalidate`, `autocomplete` | `noValidate`, `autoComplete` |
| `<img ...>` `<input ...>` | `<img ... />` `<input ... />` |
| `style="max-width: 640px"` | `style={{ maxWidth: 640 }}` — **строка = белый экран** |
| `<!-- ... -->` | `{/* ... */}` |

### 1б. Роуты ✅
```jsx
const router = createBrowserRouter([
  {
    path: "/",
    element: <App />,                        // App = Header + <Outlet />
    children: [
      { index: true, element: <Home /> },    // "/"
      { path: "books/:id", element: <Book /> },
      { path: "new", element: <BookForm key="new" /> },
      { path: "books/:id/edit", element: <BookForm key="edit" /> },
    ],
  },
]);
```
`path` в `children` — без `/` в начале. `:id` — переменная часть адреса.

### 1в. Ссылки
```jsx
import { Link, NavLink } from "react-router-dom";

<Link to="/books/1">Открыть</Link>                          // вместо <a href>
<Link to={`/books/${book.id}/edit`}>Изменить</Link>          // id из данных (с шага 4)

<NavLink to="/" end className={({ isActive }) => (isActive ? "is-active" : "")}>
  Главная
</NavLink>
```
- в `Link` путь **всегда с `/` в начале**, иначе он приклеится к текущему адресу;
- `:id` в `Link` не пишется — только настоящее число;
- `NavLink` сам передаёт в функцию `{ isActive }`; `end` — только у ссылки на `/`.

**Осталось у тебя:**
- `Header.jsx`: убрать `href="register.html"` у «Регистрации», блок гостя — в `{/* */}`
  (условие будет в шаге 3);
- `Home.jsx`, `My.jsx`: оставить **по одной** карточке, остальные удалить (с шага 4 они
  рисуются из данных), у оставшейся — `Link` на `/listings/1` и `/listings/1/edit`;
- `Login`, `Register`, `Form`: `for` → `htmlFor`, `novalidate` → `noValidate`,
  `autocomplete` → `autoComplete`;
- в `main.jsx` двум роутам с `<Form />` дать разные `key` (зачем — шаг 6).

**Проверка:** по всем 7 адресам проходишь **кликами**, белых экранов нет, в консоли (F12)
нет красного, пункт меню подсвечивается.

## Шаг 2. `src/api.js`

Весь обмен с сервером — в одном файле. Страницы вызывают готовые функции (`listings()`,
`login(...)`) и не думают про заголовки и токен.

### Код (выучить)
```js
export const API_URL = "http://localhost:4000";
export const WS_URL = "ws://localhost:4000/ws";

// токен — строка, localStorage хранит строки: JSON не нужен
export const getToken = () => localStorage.getItem("token");
export const setToken = (token) => localStorage.setItem("token", token);
export const removeToken = () => localStorage.removeItem("token");

const request = async (path, options = {}) => {
    const headers = {};
    const token = getToken();
    if (token) headers.Authorization = `Bearer ${token}`;

    let body = options.body;
    if (body && !(body instanceof FormData)) {
        headers["Content-Type"] = "application/json";   // объект → JSON
        body = JSON.stringify(body);
    }                                                   // FormData — как есть, без Content-Type

    const res = await fetch(API_URL + path, {
        method: options.method || "GET",
        headers,
        body,
    });

    if (res.status === 204) return null;                // DELETE: тела нет
    const data = await res.json();
    if (!res.ok) throw { status: res.status, ...data }; // в catch: err.status, err.errors
    return data;
};

export const register = (email, password) =>
    request("/api/register", { method: "POST", body: { email, password } });
export const login = (email, password) =>
    request("/api/login", { method: "POST", body: { email, password } });
export const me = () => request("/api/me");

export const listings = (sort) => request(sort ? `/api/listings?sort=${sort}` : "/api/listings");
export const myListings = () => request("/api/listings/mine");
export const listing = (id) => request(`/api/listings/${id}`);
export const contact = (id) => request(`/api/listings/${id}/contact`);
export const createListing = (formData) => request("/api/listings", { method: "POST", body: formData });
export const updateListing = (id, formData) => request(`/api/listings/${id}`, { method: "PUT", body: formData });
export const deleteListing = (id) => request(`/api/listings/${id}`, { method: "DELETE" });
```

Порядок в `request` важен: **сначала** проверка 204, **потом** `res.json()`.

### Проверка
Временно в `Home.jsx` (перед `return`):
```jsx
import { useEffect } from "react";
import { listings, login } from "../api.js";

useEffect(() => {
    listings().then(console.log);
    login("seller@example.com", "wrong").catch(console.log);
}, []);
```
В консоли: `{data: Array(6)}` и `{status: 422, message: "Invalid data", errors: {…}}`
(каждое дважды — это `StrictMode`, норма). Потом удалить.

### Частые ошибки
- путь без `/` в начале: `API_URL + "api/me"` = `http://localhost:4000api/me` → `Failed to fetch`;
- `api/listing/` вместо `api/listings/` → 404;
- `Failed to fetch` на всех запросах → не запущен бэк.

## Шаг 3. Регистрация, вход, выход

### Что знать

**`useState`** — переменная, при изменении которой React перерисовывает компонент.
**Управляемый input** — значение хранится в state, input его только показывает:
```jsx
const [title, setTitle] = useState("");
<input value={title} onChange={(e) => setTitle(e.target.value)} />
```

**Контекст** — данные, доступные любому компоненту без передачи через пропсы. Нужен,
потому что «кто вошёл» знают хедер, защищённые роуты и страницы входа.

### 3.1 `src/auth.jsx` (выучить)
```jsx
import { createContext, useContext, useEffect, useState } from "react";
import { getToken, setToken, removeToken, me, login as apiLogin } from "./api.js";

const AuthContext = createContext(null);

export const AuthProvider = ({ children }) => {
    const [user, setUser] = useState(null);     // null — гость, { email } — вошёл
    const [ready, setReady] = useState(false);  // проверили ли токен при старте

    useEffect(() => {
        if (!getToken()) {
            setReady(true);
            return;
        }
        me()
            .then((data) => setUser({ email: data.email }))
            .catch(() => removeToken())         // токен протух — забываем
            .finally(() => setReady(true));
    }, []);

    const login = async (email, password) => {
        const data = await apiLogin(email, password);  // ошибка улетит в catch страницы
        setToken(data.token);
        setUser({ email: data.email });
    };

    const logout = () => {
        removeToken();
        setUser(null);
    };

    return (
        <AuthContext.Provider value={{ user, ready, login, logout }}>
            {children}
        </AuthContext.Provider>
    );
};

export const useAuth = () => useContext(AuthContext);
```
В `main.jsx`: `<AuthProvider><RouterProvider router={router} /></AuthProvider>`.

Зачем `ready`: пока `me()` не ответил, `user` = `null`, и без флага при F5 вошедшего
выкинет на `/login`.

### 3.2 `components/Field.jsx` (выучить)
```jsx
const Field = ({ label, htmlFor, required, error, children }) => (
    <div className={error ? "field has-error" : "field"}>
        <label className={required ? "required" : ""} htmlFor={htmlFor}>{label}</label>
        {children}
        {error && <p className="error-text">{error}</p>}
    </div>
);

export default Field;
```
`{error && ...}` — «если есть ошибка, нарисуй `<p>`».

### 3.3 Форма — один шаблон на все формы проекта
Пример — вход в «Книжную полку»:
```jsx
import { useState } from "react";
import { Link, useNavigate } from "react-router-dom";
import { useAuth } from "../auth.jsx";
import Field from "../components/Field.jsx";

const SignIn = () => {
    const { login } = useAuth();
    const navigate = useNavigate();
    const [email, setEmail] = useState("");
    const [password, setPassword] = useState("");
    const [errors, setErrors] = useState({});   // { email: ["..."], password: ["..."] }

    const handleSubmit = async (e) => {
        e.preventDefault();                     // без этого страница перезагрузится
        setErrors({});
        try {
            await login(email, password);
            navigate("/");                      // куда после успеха
        } catch (err) {
            setErrors(err.errors || {});
        }
    };

    return (
        <form className="auth-card" onSubmit={handleSubmit} noValidate>
            <Field label="E-mail" htmlFor="email" required error={errors.email?.[0]}>
                <input id="email" type="email" value={email} onChange={(e) => setEmail(e.target.value)} />
            </Field>
            <Field label="Пароль" htmlFor="password" required error={errors.password?.[0]}>
                <input id="password" type="password" value={password} onChange={(e) => setPassword(e.target.value)} />
            </Field>
            <button type="submit" className="btn btn-primary btn-block">Войти</button>
        </form>
    );
};
```
- `errors.email?.[0]` — первое сообщение по полю; `?.` — «если `errors.email` нет,
  вернуть `undefined`, а не упасть»;
- `noValidate` — валидирует **сервер** (так в ТЗ), браузерные подсказки выключены.

### 3.4 Что сделать
- **Login.jsx** — как пример выше: после успеха `navigate("/")`.
- **Register.jsx** — то же, но вызывается `register(email, password)` из `api.js`
  (не из контекста), после успеха `navigate("/login")`.
- **Header.jsx** — `const { user, logout } = useAuth();` и условие:
  ```jsx
  {user ? (
      <div className="header__actions">...+ Разместить, {user.email}, Выйти...</div>
  ) : (
      <div className="header__actions">...Войти, Регистрация...</div>
  )}
  ```
  «Мои объявления» в меню — `{user && <NavLink ...>}`. «Выйти»:
  `onClick={() => { logout(); navigate("/"); }}` (`useNavigate` из роутера).
- **components/ProtectedRoute.jsx** (выучить):
  ```jsx
  import { Navigate, Outlet } from "react-router-dom";
  import { useAuth } from "../auth.jsx";

  const ProtectedRoute = () => {
      const { user, ready } = useAuth();
      if (!ready) return null;                         // ещё проверяем токен
      if (!user) return <Navigate to="/login" replace />;
      return <Outlet />;                               // пускаем дальше
  };

  export default ProtectedRoute;
  ```
  В `main.jsx` — группа в `children`:
  ```jsx
  {
      element: <ProtectedRoute />,
      children: [
          { path: "my", element: <My /> },
          { path: "new", element: <Form key="new" /> },
          { path: "listings/:id/edit", element: <Form key="edit" /> },
      ],
  },
  ```

### Проверка
- регистрация пустая → оба поля красные, тексты от сервера;
- пароль `123` → «Минимум 6 символов»; занятый e-mail → ошибка у e-mail;
- успешная регистрация → страница входа;
- неверный пароль → ошибка у e-mail; верный → главная, в хедере e-mail;
- F5 — всё ещё вошёл; «Выйти» — гость; гостем `/my` → `/login`;
- F12 → Application → Local Storage: **только** `token`.

### Частые ошибки
- `useAuth()` вернул `null` → `AuthProvider` не обёрнут вокруг `RouterProvider`;
- форма перезагружает страницу → забыл `e.preventDefault()`;
- `A component is changing an uncontrolled input to be controlled` → `useState()` без
  начального `""`.

## Шаг 4. Список и сортировка

### Что знать
Серверных компонентов тут нет (в отличие от Next): данные грузит сама страница — state
под данные + `useEffect`, который делает запрос.
```jsx
const [books, setBooks] = useState([]);
const [sort, setSort] = useState("");

useEffect(() => {
    getBooks(sort).then((res) => setBooks(res.data));
}, [sort]);                    // перезапуск при каждой смене sort
```
**Список** — `.map()`, у каждого элемента уникальный `key`:
```jsx
{books.length === 0 ? (
    <div className="empty-state">Пусто</div>
) : (
    <div className="grid">
        {books.map((book) => <BookCard key={book.id} book={book} />)}
    </div>
)}
```
**Компонент с пропсами:**
```jsx
const BookCard = ({ book, onDelete }) => (
    <article className="card">
        <Link to={`/books/${book.id}`}><img src={book.cover_url} alt={book.title} /></Link>
        {/* 14500 → «14 500» */}
        <p>{book.price.toLocaleString("ru-RU")} ₽</p>
        {/* кнопка — только если onDelete передали */}
        {onDelete && (
            <button onClick={() => onDelete(book.id)}>Удалить</button>
        )}
    </article>
);
```

### Что сделать
- **components/ListingCard.jsx** — разметка карточки из шаблона, пропсы `listing` и
  необязательный `onDelete` (кнопки «Редактировать / Удалить» — только если он есть,
  это для шага 7). Картинка — `listing.image_url` (адрес уже полный).
- **Home.jsx** — state `listings` и `sort`, `useEffect` с `[sort]`, `<select>`
  управляемый: `value={sort}` и `onChange={(e) => setSort(e.target.value)}`. Пустой
  список — `.empty-state`. Уведомление (`toast-stack`) пока закомментировать — шаг 8.

Сортирует **сервер** (`?sort=`), на клиенте массив не сортируем.

### Проверка
6 карточек, новые сверху; «по возрастанию» — первой лампа за 900 ₽; «по убыванию» —
iPhone за 32 000 ₽. Гостем тоже работает.

### Частые ошибки
- `Cannot read properties of undefined (reading 'map')` → положил в state весь ответ, а
  массив лежит в `res.data`;
- предупреждение `Each child in a list should have a unique "key"` → нет `key`;
- запросы идут бесконечно → в зависимостях `useEffect` то, что меняется внутри него.

## Шаг 6. Создание и редактирование

### Что знать
Файл нельзя отправить JSON-ом — только `FormData`:
```jsx
const [title, setTitle] = useState("");
const [price, setPrice] = useState("");
const [cover, setCover] = useState(null);         // File

<input type="file" accept="image/*" onChange={(e) => setCover(e.target.files[0])} />
// у file-input НЕТ value

const fd = new FormData();
fd.append("title", title);
fd.append("price", price);
if (cover) fd.append("cover", cover);             // без нового файла старая картинка останется
```

Один компонент на создание и редактирование — режим по `id`:
```jsx
const { id } = useParams();
const isEdit = Boolean(id);                        // /new — id нет, /books/5/edit — есть
const [currentCover, setCurrentCover] = useState(null);   // превью старой картинки
const [forbidden, setForbidden] = useState(false);        // чужая книга
const [errors, setErrors] = useState({});
const navigate = useNavigate();

useEffect(() => {
    if (!isEdit) return;
    getBook(id).then((res) => {
        setTitle(res.data.title);
        setPrice(String(res.data.price));
        setCurrentCover(res.data.cover_url);
        if (!res.data.is_mine) setForbidden(true);
    });
}, [id, isEdit]);

const handleSubmit = async (e) => {
    e.preventDefault();
    setErrors({});
    const fd = ...;
    try {
        const res = isEdit ? await updateBook(id, fd) : await createBook(fd);
        navigate(`/books/${res.data.id}`);
    } catch (err) {
        setErrors(err.errors || {});
    }
};
```

### Что сделать
**Form.jsx** — поля `title`, `description`, `price`, `image` через `Field`, как в шаге 3.
- заголовок: `isEdit ? "Редактировать объявление" : "Новое объявление"`;
- при редактировании — превью текущей картинки (`.listing-form__current-image`) и
  подсказка «Оставьте пустым…»;
- чужое объявление (`is_mine === false`) — вместо формы сообщение «Это не ваше объявление».

**Зачем `key` на роутах:** оба роута рисуют `<Form />` в одном месте, и React
переиспользует компонент **вместе со state**. Без разных `key` при переходе с
редактирования на «+ Разместить» в форме останутся старые значения.

### Проверка
- пустая форма → красные название, цена, изображение;
- цена `0` → «Цена должна быть больше 0»;
- создал с картинкой → открылась страница нового объявления, на главной оно первое;
- отредактировал только цену → цена новая, картинка прежняя;
- buyer открывает `/listings/<id>/edit` объявления seller → сообщение, формы нет.

### Частые ошибки
- сервер говорит «Загрузите изображение», хотя файл выбран → в `api.js` на `FormData`
  ставится `Content-Type` или делается `JSON.stringify`;
- `fd.append("image", image)` при `image = null` → на сервер уходит строка `"null"`.

## Шаг 7. Мои объявления и удаление

### Что знать
Удалить из state — `filter`, перезапрашивать весь список не нужно:
```jsx
const handleDelete = async (id) => {
    if (!window.confirm("Удалить?")) return;
    await deleteBook(id);
    setBooks((prev) => prev.filter((b) => b.id !== id));
};

{books.map((b) => <BookCard key={b.id} book={b} onDelete={handleDelete} />)}
```
`setBooks((prev) => ...)` — функция получает **актуальный** state; так правильно
всегда, когда новое значение считается из старого.

### Что сделать
**My.jsx** — `myListings()` в `useEffect`, карточки `ListingCard` с `onDelete`,
пустой список — «У вас пока нет объявлений».

### Проверка
seller видит 4, buyer — 2. Удалил → карточка пропала сразу, на главной её тоже нет.

## Шаг 8. WebSocket

### Что знать
Сокет открывается в `useEffect` и **закрывается в функции очистки** (её `useEffect`
вызывает при уходе со страницы):
```jsx
useEffect(() => {
    const socket = new WebSocket(WS_URL);

    socket.onmessage = (e) => {
        const msg = JSON.parse(e.data);
        if (msg.type === "book:new") {
            setToasts((prev) => [...prev, msg.book]);
            getBooks(sort).then((res) => setBooks(res.data));   // перечитать с текущей сортировкой
        }
    };

    return () => socket.close();
}, [sort]);
```
- `sort` в зависимостях: иначе обработчик навсегда запомнит `sort` с первого рендера;
- перечитать список проще, чем вставлять вручную: порядок всегда правильный при любой
  сортировке;
- в dev `StrictMode` открывает сокет дважды (одно сразу закрыто) — норма.

### Что сделать
В **Home.jsx**: state `toasts`, эффект как выше (`type === "listing:new"`, данные в
`msg.listing`). Уведомления — разметка `toast-stack` из шаблона через `toasts.map(...)`,
крестик: `setToasts((prev) => prev.filter((t) => t.id !== id))`.

Только на главной — ТЗ: «у всех пользователей, находящихся на странице со списком».

### Проверка
Две вкладки: в первой гость на главной, во второй seller создаёт объявление. В первой
без F5 — уведомление и новая карточка. F12 → Network → WS: после ухода с главной и
возврата живое соединение одно.

## Шпаргалка

### Next.js → React + React Router
| Next.js | Здесь |
|---|---|
| файл `app/my/page.jsx` | `{ path: "my", element: <My /> }` |
| `layout.jsx` с `{children}` | `App.jsx` с `<Outlet />` |
| `<Link href="/my">` из `next/link` | `<Link to="/my">` из `react-router-dom` |
| папка `[id]` | `:id` в пути |
| `useParams()` | `useParams()` — то же |
| `useRouter().push("/x")` | `const navigate = useNavigate(); navigate("/x")` |
| `redirect("/login")` | `<Navigate to="/login" replace />` |
| `async` серверный компонент с `fetch` | `useState` + `useEffect` с запросом |
| `'use client'` | не нужен — всё клиентское |

### Хуки
| Хук | Зачем |
|---|---|
| `useState(начальное)` | значение, при изменении — перерисовка |
| `useEffect(() => {...}, [зависимости])` | код после рендера: запросы, сокет. `[]` — один раз |
| `useContext` / свой `useAuth()` | общие данные (кто вошёл) |
| `useParams()` | `:id` из адреса |
| `useNavigate()` | переход из кода |

Хуки — только на верхнем уровне компонента, не внутри `if`, циклов и обработчиков.

### Ошибка → причина
| Видишь | Причина |
|---|---|
| `X is not defined` | забыл `import X` **в этом** файле |
| белый экран, `style prop expects a mapping` | `style="..."` строкой → `style={{ ... }}` |
| текст `/* ... */` на странице | комментарий в JSX только `{/* ... */}` |
| адрес `/my/listings/1` | в `Link` путь без `/` в начале |
| «страница не найдена» роутера | путь в `Link` не совпал с роутом (`listing` / `listings`) |
| `Failed to fetch` | бэк не запущен или адрес склеился без `/` |
| форма перезагружает страницу | нет `e.preventDefault()` |
| `reading 'map'` of undefined | в state не массив — `res.data` |
| бесконечные запросы | неправильные зависимости `useEffect` |
| в форме старые значения при переходе | одинаковый компонент на двух роутах без `key` |
