# Модуль В — клиент «Барахолки» (тренажёр)

SPA на React под свой Django-бэк из `../module-c-backend`. Код пишешь сам,
порядок работы — в [docs/ПЛАН.md](docs/ПЛАН.md).

| Что | Где | Откуда |
|---|---|---|
| План: шаги, файлы, проверки, чек-лист | [docs/ПЛАН.md](docs/ПЛАН.md) | тренажёр |
| Официальный текст задания | [docs/ТЗ-модуль-В-официальное.md](docs/ТЗ-модуль-В-официальное.md) | `04-Конкурсное-задание-основная.docx`, дословно |
| Документация API | [docs/api.md](docs/api.md) | тренажёр |
| Вёрстка («предоставленный шаблон») | [шаблон/](шаблон/) | тренажёр |
| Твой клиент | `client/` | появится в шаге 1 плана |

⚠️ **Выдумано:** API, шаблон и картинки. На площадке шаблон и документацию к API
выдают в медиафайлах, и они будут другими. Шаблон собран из вёрстки эталонного
клиента (`готовые-работы/придуманные/module-c-spa`), потому что прежний
`module-c-prep/шаблон` удалён. В шаблоне исправлен один баг: `.section` обнулял
боковые отступы `.container`.

**Реальное:** текст ТЗ и то, что он требует: SPA, роутер, токен в `Authorization`,
серверная валидация с подсветкой полей, e-mail по клику, WebSocket у гостя и у
вошедшего, в `localStorage` только токен.

## Запуск

```bash
# сервер (терминал 1)
cd ../module-c-backend/backend
python manage.py seed
python manage.py runserver 4000

# шаблон — открыть страницы и сравнивать (терминал 2)
cd шаблон
python3 -m http.server 8765        # http://localhost:8765

# клиент (терминал 3, после шага 1)
cd client
npm run dev                         # http://localhost:5173
```

Аккаунты: `seller@example.com` / `buyer@example.com`, пароль `secret123`.
